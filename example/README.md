# M3E Loading Example

Demo app showcasing all features of the m3e_loading package.

## Running the Example

```bash
cd example
flutter pub get
flutter run
```

## What's Demonstrated

- All 5 size variants (XS, SM, MD, LG, XL)
- Custom color overrides
- Integration with Material 3 theme
- Responsive layout
- Clean, professional UI
